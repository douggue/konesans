# Konesans admin: web and phone

The web admin (`apps/admin-web`, at `https://admin.<your-server>`) and the phone app **Konesans Admin**
(`apps/admin-mobile`) do the same things against the same server API (`docs/API.md`).
When a feature is added to one, add it to the other and to this table.

| Feature | Web | Phone |
|---|---|---|
| Log in / log out | ✓ | ✓ |
| Dashboard: question counts by status, players, open reports | ✓ | ✓ |
| Dashboard tiles open the matching question list | ✓ | ✓ |
| Review progress per category | ✓ | ✓ |
| Publish to kids' phones (with confirmation) | ✓ | ✓ |
| Import the bundled question bank (when the server is empty) | ✓ | ✓ |
| Questions: filter by category, status, age, search | ✓ | ✓ |
| Quick approve / flag, with undo | ✓ (buttons) | ✓ (swipe right / left) |
| Edit question: Kreyòl + French, options, right answer, explanation, ages, level, topic, note | ✓ | ✓ |
| Warnings (empty fields, duplicate options, non-Kreyòl letters) | ✓ | ✓ |
| Save · Approve · Flag · Back to review · Delete | ✓ | ✓ |
| Warning before leaving unsaved changes | ✓ | ✓ |
| Add a new question | ✓ | ✓ |
| Categories: add, rename, reorder, show/hide, "Nouvo", colour, picture, ages | ✓ | ✓ |
| App settings: features on/off, announcement, maintenance, review questions, daily count, min version | ✓ | ✓ |
| App texts (Kreyòl + French overrides) | ✓ | ✓ |
| Reports from duels (resolve) | ✓ | ✓ |
| History of admin changes | ✓ | ✓ |
| My account: change password | ✓ | ✓ |
