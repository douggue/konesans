# Design files

- `project/` — the clickable mockup (Design canvas artboards, `*.dc.html` + `canvas.json`). Mirror of the Claude Design artifact.
- `iconset/` — the 66 in-app icons as SVG (source of `apps/mobile/src/ui/icons.ts`).
- `emblem-silhouette.svg` — the coat of arms flattened to white (from the MIT-licensed flag-icons flag), used on blue cards.
- `konesans-relekti.xlsx` — every user-facing string, for proofreading.
